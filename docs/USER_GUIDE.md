# User guide

1. Select or drag a PDF into the workspace and choose a bank or **Automatic**.
2. Enter the PDF password only when required, then choose **Extract**.
3. Confirm column mapping if it appears. Scanned pages automatically use OCR when Tesseract is configured.
4. Review every transaction. Correct dates, descriptions, debit/credit values, voucher types, ledger matches, duplicates, and ignored rows.
5. Connect to Tally and download the open company's ledgers.
6. Validate vouchers. Resolve every blocking error.
7. Preview XML, export selected/all vouchers, or import directly to Tally.
8. Review **History** for import results and retry failed rows when appropriate.

Use **Settings & Tools > App** for OCR, logging, export location, theme, manual backup, and daily automatic backups. Backups retain the configured number of newest archives (seven by default).
