# Sample data

`sample_transactions.csv` contains synthetic data only. It demonstrates Payment, Receipt, an own-account transfer, bank charges, interest, cash withdrawal and deposit, cheque, UPI, NEFT, multiline narration, a probable duplicate, an invalid date, and a row intended to remain unmatched.

It contains no real account number, person, company, UTR, cheque, or banking information. It can be converted to PDF for import testing or used as a reference when comparing the transaction review and Excel export.

`sample_tally_vouchers.xml` is a Phase 4 Tally Prime import example generated by the application. It contains synthetic Payment, Receipt, Contra, and bank-charge vouchers for `Demo Company`, with balanced ledger entries, correct Tally debit/credit flags, and bank allocation details. Change the company and ledger names before using it with a real Tally company.
